grok-export-tool

A local copy of your Grok Bots and your regular Grok chats, plus a small MCP server for the Bot archive.

It runs on your Mac, in the Chrome profile where you are already logged in to grok.com. It reads history you already have. It does not send new chats.

Read the guide View the source

Features

  • Every Grok Bot the signed-in Chrome session can see: roster, full transcript, and attachments, in parallel 4 MB chunks.
  • Regular Grok chats in a second folder: Markdown, raw JSON, and one combined JSONL file.
  • A messages-only Bot export when you want the text without attachment downloads.
  • A stdio MCP server with no third-party dependencies: list_bots, get_bot, search. It reads the Bot archive.
  • An OpenCode skill in the repository for the export-and-query workflow.

macOS and Google Chrome only. Profiles scanned: Default, Profile 1, and Profile 2. Chat export records text and raw JSON; it does not download attachment files.

Quick start

git clone https://github.com/LofiSu/grok-export-tool.git
cd grok-export-tool
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt

python3 grok-bot-export.py                  # Bots, with attachments
python3 grok-bot-export.py --messages-only  # Bots, text only
python3 grok-bot-export.py --mode chat      # regular chats
python3 grok-bot-export.py --mode all       # both

The first run asks macOS for the Keychain item Chrome Safe Storage. Allow it. Output goes to ~/Downloads/ unless you pass a directory. Progress lines are in Chinese. The guide covers each mode, the archive, OpenCode, and the failures that actually happen.

MCP

grok-bot-mcp.py speaks MCP over stdio. Pass it the Bot export directory. It does not open a network connection, and it does not index a regular chat export.

OpenCode configuration, Claude Code, Codex, and Cursor are written out in the guide.

Output layout

Bots land in ~/Downloads/grok-bot-export-YYYYMMDD/. Each Bot is a numbered folder with messages.jsonl, conversation.md, transcript.json, and attachments/. Start with _index.md.

Regular chats land in ~/Downloads/grok-chat-export-YYYYMMDD/, with one Markdown file and one JSON file per conversation. With --mode all and a directory you chose, chats are written to that path plus -chat.
