grok-export-tool

导出你的 Grok Bot 和普通对话。本地命令行、MCP server 与 Agent skills。全程本地，无需 API key。

给已经登录 grok.com 的 Chrome 用的本地导出器：带附件的 Grok Bot，以及普通 Grok 对话。它读取你已经有的历史，不发送新对话。

阅读教程 查看源码

特性

  • 当前 Chrome 登录态能看到的全部 Grok Bot：名单、完整记录、附件。附件按 4MB 分块并行下载。
  • 普通 Grok 对话在另一个目录：Markdown、原始 JSON，以及一份合并的 JSONL。
  • 本地命令行可以导出 Bot、普通对话，或两者一起；也可以只导出 Bot 的文字。
  • 零第三方依赖的 stdio MCP server：list_bots、get_bot、search。它读取的是 Bot 归档。
  • Agent Skill 在 .claude/skills/grok-export/，Claude Code、OpenCode 以及其他会加载这个目录的 Agent 都能用。

macOS 通过钥匙串读取 Chrome。Windows 可以用 DPAPI。Linux 是尽力而为，三个平台都可以用 --cookie。普通对话导出保存文本和原始 JSON，不下载附件文件。

快速开始

git clone https://github.com/LofiSu/grok-export-tool.git
cd grok-export-tool
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt

python3 grok-bot-export.py                  # Bot，含附件
python3 grok-bot-export.py --messages-only  # Bot，只要文字
python3 grok-bot-export.py --mode chat      # 普通对话
python3 grok-bot-export.py --mode all       # 两者都导出

第一次运行时，macOS 会询问钥匙串项目 Chrome Safe Storage。选择允许。Windows 和 Linux 在自动解密失败时可以用 --cookie。未指定目录时，文件写到 ~/Downloads/。进度日志是中文。逐步说明在下面的教程。

MCP

grok-bot-mcp.py 通过 stdio 提供 MCP。把 Bot 导出目录传给它。它自己不发起网络连接，也不索引普通对话导出。

OpenCode、Claude Code、Codex 和 Cursor 的配置写在教程里。

输出布局

Bot 在 ~/Downloads/grok-bot-export-YYYYMMDD/。每个 Bot 是一个带序号的文件夹，里面有 messages.jsonl、conversation.md、transcript.json 和 attachments/。先看 _index.md。

普通对话在 ~/Downloads/grok-chat-export-YYYYMMDD/，每个会话一份 Markdown 和一份 JSON。--mode all 同时又指定了目录时，普通对话写到该路径加上 -chat。
